## Play Console: App content answers

**Privacy policy:** https://coderasraf.github.io/Waqt/privacy.html

**Ads:** No, the app doesn't contain ads.

**App access:** All functionality is available without special access (no login).

**Content rating (IARC questionnaire):** Category is "Reference, News, or Educational" (or "All other app types"). Answer **No** to violence, sexuality, language, controlled substances, gambling, user interaction/chat, sharing location with other users and digital purchases. The expected rating is Everyone / 3+.

**Target audience and content:** 13–15, 16–17 and 18+. Don't include under-13 groups; that would bring in the Families policy for no benefit. The app isn't designed for children.

**News app:** No.

**Government app:** No.

**Financial features:** None.

**Health:** None.

**Data safety**
- Does your app collect or share any required user data types? **Yes**
  - **Location → Approximate location**: Collected, **not shared**
    - Processed ephemerally: **Yes** (sent once to reverse-geocode a city name when the user taps "Detect my location"; nothing is stored off the device)
    - Required or optional: **Optional** (users can type their city)
    - Purpose: **App functionality**
  - No other data types (no personal info, no contacts, no app activity, no device IDs, no crash logs).
  - Backups are saved by the user to a file or Google Drive of their choice; Waqt itself never uploads them. Android's own backup (if on) is Google's, not the developer's.
  - Online content (Quran recitation, tafsir, hadith chapters, dua audio, the Bangladesh Hijri file) is downloaded; no user data is sent with these requests.
- Is all collected data encrypted in transit? **Yes** (HTTPS only)
- Do you provide a way for users to request deletion? Data isn't retained off the device; users can clear the app's storage. Choose the option that says data is not stored or is deleted automatically, if offered.

**Foreground service declaration** (Policy → App content → Foreground service permissions)
- Types used: **systemExempted** (adhan) and **mediaPlayback** (adhan preview and the Quran audiobook).
- Description:
  > Waqt is a Muslim prayer-time app. At each of the five daily prayer times, an exact alarm (the user grants "Alarms & reminders") starts a foreground service that plays the adhan (call to prayer) audio for about 2–4 minutes, with a notification that lets the user stop it. Android permits the systemExempted type for apps holding SCHEDULE_EXACT_ALARM to continue alarms. mediaPlayback is used when the user plays an adhan preview, and for the Quran audiobook the user starts (a media session with lock-screen controls, so recitation continues with the screen off). The service stops as soon as the audio ends or the user taps Stop/Pause.
- User impact if deferred: "The call to prayer would play late or not at all, so the user misses the prayer time. The Quran recitation the user started would stop when the screen turns off."
- Video: upload `fgs-demo.mp4` (in this folder) to YouTube as **Unlisted** and paste the link. It shows the test adhan firing on a locked phone and the Stop action.

**Exact alarms:** the app uses `SCHEDULE_EXACT_ALARM`, which the user grants in onboarding. No declaration is needed. `USE_EXACT_ALARM` is **not** used.

**Location:** foreground, approximate only. No background location, so no declaration is needed.
